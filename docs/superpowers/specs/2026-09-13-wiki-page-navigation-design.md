# Wiki 页面阅读导航设计

## 目标

为生成的 wiki HTML 页面统一添加“返回上一页”和“推荐阅读下一页”区域，使 `wiki/index.md` 成为稳定的线性阅读路径，同时保留页面之间基于 `related` 的知识图谱跳转。

## 方案

只修改 `wiki/html-assets/build.py` 与必要的 CSS，不在 Markdown 页面中写入导航内容。构建器解析 `wiki/index.md` 中按出现顺序排列的 wikilink，解析为可生成 HTML 的页面序列，并在每个内容页底部注入导航。

## 行为

- 上一页：序列中当前页的前一个页面；不存在时显示“返回索引”。
- 推荐阅读下一页：序列中当前页的后一个页面；不存在时显示“返回索引”。
- 相关页面：读取页面 frontmatter 的 `related`，展示已存在的实体、概念、源文件或分析页。
- 首页/日志页：不参与内容页的前后序列，提供返回索引或进入第一篇内容的入口。
- 未出现在 `wiki/index.md` 的内容页：不猜测顺序，显示返回索引和相关页面。
- 缺失或重复 wikilink：跳过，不让构建失败。

## UI

导航栏放在主内容之后、页脚之前，使用现有页面风格。上一页、下一页和相关页面使用明确的文字标签与可点击链接；在窄屏上允许三块内容换行。

## 验证

- 构建器成功生成所有 HTML。
- 任意实体、概念、源文件页面均包含导航区域。
- 第一页/最后一页的边界链接正确。
- 未索引页面不会生成错误链接。
- 现有 wikilink、frontmatter、手工 HTML 跳过规则保持不变。
